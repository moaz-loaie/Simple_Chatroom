# Simple Chatroom (Go + RPC)

This project implements a simple chatroom using Go and the net/rpc package. See PLAN.md for details.

## Quick Start

1. Build the server:
   ```powershell
   go build ./cmd/server
   ```
2. Run the server:
   ```powershell
   .\server.exe
   ```
3. Build the client:
   ```powershell
   go build ./cmd/client
   ```
4. Run the client:
   ```powershell
   .\client.exe
   ```

See PLAN.md for full requirements, design, and usage.
